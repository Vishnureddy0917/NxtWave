## ⚡ What is NxtWave EvalAI?
Instead of a passive, generic landing page (which everyone builds), **NxtWave EvalAI** gives final-year engineering students **instant pre-workshop validation**:
1. **Multi-Branch Project Auditing:** Tailored tracks for CSE/IT, ECE/EEE, Mechanical, and Civil engineering.
2. **Instant Rubric Scoring:** Real-time analysis across Prompt Engineering, API Resilience, Error Boundaries, and Code Architecture.
3. **ATS-Ready Resume Bullets:** 1-click export of recruiter-ready bullets with placement metrics.
4. **Verifiable Skill Credential:** Digital certificate with a unique audit credential ID.
5. **Growth & Referral Loop:** College battle leaderboard (SRM AP vs VIT-AP vs KL University) with pre-drafted 1-click WhatsApp sharing.

## 🛠️ Local Development
To run this project locally without any installation or build steps:
```bash
# Clone the repository
git clone https://github.com/Vishnureddy0917/NxtWave.git
cd NxtWave

# Start a local static server
python -m http.server 8000
# Open http://localhost:8000 in your browser
```
